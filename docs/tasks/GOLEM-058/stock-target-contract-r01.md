# Standalone candidate stock-MOS check

Compile every shipped example on the emulated Agon, then execute its stock
buffered output. This checks what a recipient can actually do with the ZIP,
without a VDPlet runtime or a second compiler implementation.

The selected archive is candidate r01, SHA256
0edce1573beb32fd3f0acb0b04ea7dfcfd06b04206289d5650b594446e4dbc91.
The frozen cohort contains the exact extracted ZIP, thirteen response-file
jobs, PC-reference bytes, and a test-only client including the unmodified
shipped runner. The thirteenth job also exercises assembly/AGNB load-plan output.
The native-only trig example emits C but is not executed as stock VDP code.

One fresh JIT process is selected, with a600-second whole-fixture bound, normal
wrapper launch, ordinary Oryx FIFO, fresh whole-host empty evidence and exact
ownership. The previously working stock profile supplies only pinned runtime
components; its SD card and user state stay unchanged. StockVDP b807beef,
MOSd5642432, frontend7e78e991 and backend200f28cb are explicit selections,
not a new firmware/default upgrade. Create a separate project-local profile.

The application executes hello/loops and eight resident/portable examples,
checks76 result/status bytes by existing stock GP echo patching, releases
borrowed matrix buffers and draws only the native-compiled cube source. No
post-copy integrity protocol is added to production. Batch exit codes and
all emitted file bytes must match the PC reference. An ordinary MOS dir/save
continuation, zero backend faults and clean owned shutdown are required.
Archive stale outputs before startup, retain failures, retrieve/hash evidence,
then release Oryx before offline analysis. No automatic retry or GUI launch.
Human walkthrough/publication and physical qualification remain separate.
