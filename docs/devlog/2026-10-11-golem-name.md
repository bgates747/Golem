# Golem's recursive backronym

The Author selected **Golem Obtains Less Excessive Messaging** for the README
on 2026-10-11. The recursive first word is a deliberate part of the appeal;
less messaging reflects the priority of reducing eZ80/VDP wire traffic by keeping
reusable work resident. This supersedes the briefly selected “Offers” version.
