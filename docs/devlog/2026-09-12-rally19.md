## R19-03 — Hosted design v1

Defined an opt-in extension of the same C++ compiler with typed resident buffers,
fields, small float matrices, finite hosted programs, symbolic command operands
and bounded indexing. Ordinary compilation remains unchanged. The design records
stock command32/34/41 lowering, resource/alias/cache limits and required negatives.
The proposed hosted source corpus is explicitly not a parser implementation pass.
Existing compiler regressions pass again under ASan/UBSan.

Pinned firmware reading establishes three important constraints: command41 uses
one numeric format for both input/output; fixed-point output casts via unsigned
integers, so signed output needs checked positive bias/unbias; conditional word
0xFFFF collides with the missing-buffer sentinel even with two fetched operands.
The state sequence range consequently excludes 65535. A diagonal affine inverse
supplies reciprocal; command34 does not implement inversion. No firmware edits,
new arithmetic emitter or native probes occurred in this design milestone.

Rally's separate layout header/tests define 80 state bytes / 97 transport bytes,
explicit signed LE decoding and transactional host rejection. Runtime admission,
range guards and all native numerical/lifecycle behavior remain R19-04/05 work.

## R19-04 — First native arithmetic checkpoint (milestone still open)

byte encoders. Added typed buffer/field/matrix/program declarations, forward
symbolic calls, arithmetic intrinsics, bounded repeats, signed store/PLOT and
binary32 data transforms. Outward-rounded interval analysis checks store bounds
and diagonal inverse denominators without computing the program's answers on
the host. Private carry storage preserves neighboring fields. Recursive calls,
unproved stores/inverses, wrong dimensions, unsafe aliases and malformed source
reject. Ordinary compilation is unchanged; old regressions and new byte goldens
plus 26 negative cases pass under ASan/UBSan. All three intended accepts and
twelve intended rejects from the frozen hosted design corpus now execute with
the expected result; failed compilation preserves the existing output.

in the adjacent field. Diagnostic byte readback uses only stock GP echo and
buffer-field copying. No firmware changes or eZ80 arithmetic substitutes.

replacement/extraction. The finite denominator admission chain rejects 0, -1,
-2, 21 and 65536 before arithmetic, retains the preceding result and clears its
admission flag; 7 is accepted and computes a new result. This proves the kernel's
denominator guard, not the future full Rally state validator. Native repeat
counts 0/1/8/120 give 65534/65535/6/118 from initial 65534 and leave neighboring
12345 intact. Host sanitizer/golden/negative tests pass again.

Complete-intrinsics visual and capture-free cost runs both pass, with explicit
