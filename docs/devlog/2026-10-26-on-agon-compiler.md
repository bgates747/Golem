# 2026-10-26 — Compile Golem directly on Agon

GOLEM-051 delivers a task-local AgonDev/MOS compiler for every currently
implemented profile, plus a standalone SD package. A user can edit, compile and
run stock buffered programs on the Agon without a PC or LLM. Native C emission
is retained; an on-Agon C-to-Xtensa toolchain is a separate option. Human review
and publication approval remain open.

The Author requested all native-development options, expanded option 1 into the
first implementation, required full current-language coverage and specified
C/C++ targeting AgonDev. The initial subset exploration was superseded. The
port now reuses actual maintained C++ sources with a targeted platform library,
error recovery, binary64 numerical processing and unchanged generated bytes.
All new implementation remains under the task silo. Existing compiler code and
pending GOLEM-049/050 changes were preserved.

The [results](../tasks/GOLEM-051/RESULTS.md) record 316 matching native/compiler
comparisons (75 accepted, 241 rejected), clean host ASan/UBSan, 13 CLI cases, ten
native-compiled examples, 56 independently expected stock result bytes, 13 cube
anchors, 17,966 numerical comparisons and identical rebuilds of all six binaries
from the selected standalone source tree. Errors and practical RAM limits are
explicit; no remaining corpus case is classified as resource-limited.

The [how-to](../tasks/GOLEM-051/HOWTO.md),
[language reference](../language-reference.md), initialized examples and rebuilt
binaries are included in the approximately 600 KiB ZIP. Everyday use requires only
MOS/stock VDP and an editor. The installed compiler/runner review script compiles
Hello World and a white cube in mode 19, with MOS text confined below the picture.
The Pi fixture is stopped after headless numerical, visual-anchor and dir/save
checks. Oryx and the physical bench stayed off; no firmware was flashed. Work
remains uncommitted pending the Author's review.
